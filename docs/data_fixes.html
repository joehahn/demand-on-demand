Iowa liquor sales: what was fixed

Every problem documented on the data exploration page is fixed once, in the warehouse, by the loader's clean stage. The raw landing table stays exactly as published, so each fix below is shown before and after. Forecasts read only the clean tables, so none of them has to know these problems existed.

1. Duplicate rows in the state's export

1,512,965 rows repeated verbatim across CSV parts of the 2022, 2025 and 2026 downloads were removed. The portal's own 2026 row count matches the de-duplicated count.

2. Zero lines

13,258 order lines with zero bottles or zero dollars, likely cancelled lines, were removed.

3. Category codes that changed meaning

Every line now takes its item's current category, so all ten years are in today's taxonomy, and retired codes map to the live code with the same name. 2,048,106 lines changed category.
