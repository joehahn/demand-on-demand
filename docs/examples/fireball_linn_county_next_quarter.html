How far to trust it

Every month in the Testing period was forecast by a model trained only on earlier months, then compared with what actually happened and with the simplest serious baseline: the same month last year.

How the data was prepared

Monthly dollars from Jan 2016 through Aug 2026. The AI wrote the SQL query that selects the sales records for this request; fixed code adds them up, and every other step is fixed code that runs the same way for every request. The code itself was written in advance with Claude Code, with a person reviewing and approving every data fix.

What the agent did

How the AI agent (Claude) turned the request into what “Read as” shows at the top. It writes the SQL that selects the sales records (which products, which stores, which measure) and names the time grain. Fixed code then checks that the SQL can only read data, never change it; sums the selected records into monthly totals for each series; picks and tests the model; and generates this page.

The agent's toolbox. The AI agent (Claude Sonnet 5) does text-to-SQL. To turn words like “cream liqueur” or “Des Moines” into the warehouse's own codes it has 3 tools: search the names of products, categories, vendors, stores and places; run a small test query; and, in a live session, ask the requester one clarifying question when a request is ambiguous. None of them can change the data. It then writes one SQL query that selects the sales records to forecast (instructions, tools).

How it knows the tables and columns. At the start of every request the agent reads the warehouse's data dictionary from the database: 12 tables and 72 columns. Its search tools then find the actual names below. This forecast's data came from three of the tables:

The SQL as run

Written by the AI, checked to be one read-only SELECT, and run under a read-only database login, inside fixed code's own sums (by month, store and product). It selected 97,597 sales records (Jan 2016 through Aug 2026).

SELECT
  il.ordered_on AS day,
  il.store_no,
  il.item_no,
  'total' AS series,
  il.sales_dollars AS value
FROM sales.invoice_line il
JOIN sales.store s ON s.store_no = il.store_no
WHERE il.item_no IN (
  SELECT i.item_no
  FROM sales.item i
  JOIN sales.item h ON h.item_no = i.family_item_no
  WHERE h.item_desc ILIKE '%FIREBALL%'
)
AND s.county_name = 'LINN'
AND il.ordered_on >= '2016-01-01'
