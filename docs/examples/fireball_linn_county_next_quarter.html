How the model was chosen

Model: the average of the top 3 of 96 configurations (explained below); 9% more accurate than repeating last year over a 22-origin backtest on Sep 2024 to Aug 2026, months the model never trained on.

How this forecast is made. 96 model configurations were scored on Sep 2022 to Aug 2024, before the test window; a tuning error below 1 beats repeating the same month last year. The forecast uses the average of the top 3:

  1. LightGBM (gradient-boosted trees, 15 leaves) predicting monthly dollars directly from the last 12 months, trained on this series only (all history). Tuning error 0.816 vs the baseline.
  2. LightGBM (gradient-boosted trees, 15 leaves) predicting monthly dollars directly from the values 1, 2, 3 and 12 months back, trained on this series plus the same product in the 15 busiest other counties (all history). Tuning error 0.824 vs the baseline.
  3. Ridge regression predicting monthly dollars directly from the values 1, 2, 3 and 12 months back, regularization strength 10, trained on this series only (the last 5 years). Tuning error 0.837 vs the baseline.

The models alone scored better than any mix with last year's numbers, so the forecast is the average of the top 3 with no blending (tuning error 0.783).

Aggregation SQL (generated by the harness, run under the read-only role):

SELECT date_trunc('month', l.ordered_on)::date AS month,
       'total' AS series,
       l.store_no,
       sum(l.sales_dollars) AS value
FROM sales.invoice_line l
JOIN sales.item i USING (item_no)
JOIN sales.store s USING (store_no)
WHERE l.item_no = ANY(ARRAY['100413', '100423', '100535', '100642', '100847', '100938', '101151', '102031', '102057', '102096', '102214', '102445', '102556', '102780', '102945', '103039', '64858', '64863', '64864', '64865', '64866', '64867', '64868', '64870', '64904', '65013', '75969', '75971', '75972', '76302', '...'])
  AND s.county_fips = ANY(ARRAY['19113'])
  AND l.ordered_on >= '2016-01-01'
GROUP BY 1, 2, 3
ORDER BY 1, 2, 3
