  • Single combined monthly total series for the city (not broken out further).

How far to trust it

Every month in the Test period was forecast by a model trained only on earlier months, then compared with what actually happened and with the simplest serious baseline: the same month last year.

Track record beyond this forecast: across 30 sampled forecasts, the harness beat repeating last year on 23 (benchmark report); the agent turned 42 of 42 test requests (21 requests, run twice each) into exactly the right request or correctly declined them (eval report).

How the data was prepared

Monthly bottles from Jan 2016 through Aug 2026. How the data was prepared: fixed once in the warehouse, before any forecast, then shaped for this request by the harness. The AI agent takes no part in these steps: they are fixed code that runs the same way for every request. The code itself was written in advance with Claude Code, with a person reviewing and approving every data fix.

What the agent did

How the AI agent (Claude) turned the request into what “Read as” shows at the top: the exact products, place, measure and months. Its tools only look things up; it never writes the SQL or the models, and the harness checks the request before running it.

The agent's toolbox. The AI agent (Claude Sonnet 5) does slot filling: it fills in a short request form (product, place, measure, months) using 5 read-only lookup tools, and fixed code turns that form into SQL. Unlike text-to-SQL, it never writes the query that feeds the forecast (instructions, tools).

How it knows the tables and columns. At the start of every request the agent reads the warehouse's data dictionary from the database: 12 tables and 72 columns, each described in a sentence. Its search tools then find the actual names below. This forecast's data came from three of the tables:

The SQL as run

Adds up bottles per month and store for Tito's Handmade Vodka Mini (50ml, including 4-pack) (with 38180, 938180, older item numbers of the same products, so their history is complete) in Des Moines, from 2016-01 on. Generated by the harness from the request, never written by the AI, and run under a read-only database login.

SELECT date_trunc('month', l.ordered_on)::date AS month,
       'total' AS series,
       l.store_no,
       sum(l.sales_bottles) AS value
FROM sales.invoice_line l
JOIN sales.item i USING (item_no)
JOIN sales.store s USING (store_no)
WHERE l.item_no = ANY(ARRAY['38185', '38194', '38180', '938180'])
  AND s.city = ANY(ARRAY['DES MOINES'])
  AND l.ordered_on >= '2016-01-01'
GROUP BY 1, 2, 3
ORDER BY 1, 2, 3
