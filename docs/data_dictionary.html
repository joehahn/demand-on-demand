Iowa liquor warehouse: data dictionary

This is exactly what the AI agent is told about the warehouse at the start of every forecast request: 12 tables and 72 columns, each described in a sentence. The agent uses it to know which tables and columns hold products, places and sales; its search tools then find the actual names (a product, a city), and it fills in a forecast request. It never writes the SQL: the harness does. The descriptions are written once in the loader and stored in the database, so this page, the agent and any SQL client all read the same text. Raw tables and credentials are not described because the agent cannot reach them.

sales.invoice_line

One row per product line on a retailer's wholesale liquor order from the state (Iowa Class E licensees), 2016 onward, cleaned (see meta.data_fixes). Price, pack and category_code are as recorded on the order date.

columntypedescription
line_idbigintUnique id of the order line.
invoice_idtextId of the order (invoice); one order can have many lines.
ordered_ondateDate the retailer placed the order with the state.
store_notextOrdering store; joins sales.store.
item_notextProduct ordered; joins sales.item.
vendor_notextVendor of the product; joins sales.vendor.
category_codetextProduct category on the order date; joins sales.category.
packintegerSelling units per case.
bottle_volume_mlintegerVolume of one bottle in milliliters (for mini sleeves and packs, one mini; see sales.item_units).
state_bottle_costnumericPrice the state paid the vendor per bottle, in dollars.
state_bottle_retailnumericPrice the retailer paid the state per bottle, in dollars.
sales_bottlesintegerNumber of bottles ordered: a sleeve or pack of minis counts each mini when its pack size is known (sales.item_units).
sales_dollarsnumericTotal order line value in dollars.
sales_litersnumericTotal liters ordered: sales_bottles x bottle_volume_ml / 1000.
sales_bottles_recordedintegerBottles as recorded by the state: selling units, so a sleeve of 12 minis counts as 1.
sales_liters_recordednumericLiters as recorded by the state (truncated to whole liters Nov 2025 - Jan 2026).
bottle_volume_ml_recordedintegerbottle_volume_ml as recorded by the state (before 2019-08 a mini sleeve was recorded at its total volume).
